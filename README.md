# 바이브 코딩 실전

코딩을 모르는 사람을 위한 기획·프롬프트·검증 프로젝트형 실전서입니다.

바이브 코딩은 문법을 외우지 않고 말로 설명해 AI에게 만들게 하는 개발 방식입니다. 이 책은 기획자·마케터·소상공인·1인 사업자처럼 코드 문법을 모르는 독자가 기획 문서를 쓰고, AI 코딩 도구로 실제 서비스를 만들어 배포까지 하는 전 과정을 프로젝트형으로 따라갑니다.

Part 1에서는 바이브 코딩의 원리와 솔직한 한계(환각 코드·보안 구멍·유지보수 부채)를 설명합니다. Part 2에서는 AI가 이해하는 명세서 쓰기와 바로 쓰는 템플릿, 도구 고르는 법을 다룹니다. Part 3에서는 작은 단위로 나누어 시키는 법, 디버깅 대화법, GitHub을 이용한 최소한의 백업 습관을 배웁니다. Part 4에서는 하루~이틀 안에 따라 만들 수 있는 프로젝트 세 가지(포트폴리오·랜딩 배포, 업무 자동화, 결제 없는 유료 서비스 검증)를 기획부터 배포까지 완결합니다. Part 5에서는 최소 관리 루틴과 비용, 전문가에게 넘기는 법, AI 챗봇 상담원 만들기 프로젝트를 다룹니다. 마지막에는 확인 문제 20문항과 해설을 수록했습니다.
